## Repository Structure

### 📂 Code
This folder contains the firmware source code. It includes two distinct sets of code:
* **Autonomous_Nodes_Environmental_Sensors:** Code developed for our self-fabricated sensor modules.
* **Commercial_Sensor:** Code tailored for the sensor provided by the department.

### 📂 Data
This folder contains real-world environmental data collected during field testing, organized chronologically by timestamp.
* **Calibration Note:** Please note that the first two data files contain **uncalibrated** raw data. All subsequent files contain **calibrated** data.
* **Note on ACC/PPG:** The `acc''ppg' dataset may show no readings due to system instability during the initial recording phase. However, the module was fully functional and successfully demonstrated during the final demo day.

### 📂 Enclosure
This folder stores all SolidWorks CAD files for the device housing.
* **Final Assembly:** The finalized 3D model is located in the file: `Enclosure design 3D Group 6 Final.SLDASM`.

### 📂 PCB
Contains the complete PCB design files used for the project.
