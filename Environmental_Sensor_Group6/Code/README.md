#  MSc Sensor Systems Lab: Environmental Sensor Project - Group 6

##  Project Overview

* **Autonomous_Nodes_Environmental_Sensors:** Developed for the custom PCB (Task 1), utilizes the MAX30102 (PPG) for health data, the accelerometer is disabled due to hardware failure. Together with all environmental sensors.
* **Commercial_Sensor:** Developed for the department sensors nodes, utilizes the Pulse Sensor Amped (Green Light only) to capture Signal/BPM and the MPU-6050 (ACC) for motion data.
Both implementations are fully compatible with the Task 2 Environmental Sensor code and successfully perform environmental data acquisition.
